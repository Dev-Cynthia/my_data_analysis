# My Data Analysis Project - 100K Dataset

### 👩‍💻 Dev-Cynthia | Aspiring Data Analyst | Python & Data Science Enthusiast

#### 📌 About This Project
My first end-to-end data analysis project analyzing a 100,000-record dataset. This project demonstrates my skills in data cleaning, exploratory data analysis (EDA), and statistical testing.

#### 🎯 Objectives
- Clean and preprocess 100K raw dataset
- Perform Exploratory Data Analysis
- Conduct Chi-Square test for relationship between variables
- Extract actionable insights

#### 🛠️ Tools & Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- SciPy (for Chi-Square test)

#### 📊 Key Steps
1. Data Cleaning & Preprocessing
2. Exploratory Data Analysis
3. Hypothesis Testing (Chi-Square)
4. Visualization & Insights

#### 📁 Files
- `analysis.py` - Main analysis code
- `cleaned_data_100k.csv` - Cleaned dataset
- `README.md` - Project documentation

#### 🚀 What I Learned
- Handling large datasets efficiently
- Data cleaning best practices
- Statistical hypothesis testing
- GitHub portfolio building
